# Step 12 — AI gateway checklist

- [ ] Provider-agnostic gateway service created
- [ ] Secret vault/configuration strategy set; no keys in client binaries
- [ ] Approved model list and version pinning policy
- [ ] Prompt/template versioning
- [ ] Input minimization and de-identification
- [ ] Provider privacy/retention/training/region review per deployment
- [ ] Prompt injection threat tests for files and retrieved content
- [ ] Structured output schema validation
- [ ] Per-tenant/per-feature cost and rate limits
- [ ] Timeout, retry, circuit-breaker and outage states
- [ ] Output provenance and AI label visible in UI
- [ ] Clinician approval required for clinical text
- [ ] AI cannot perform privileged or irreversible actions
- [ ] Clinical evaluation, risk assessment, security review and regression tests pass
