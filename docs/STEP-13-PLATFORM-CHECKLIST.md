# Step 13 — Admin/mobile checklist

- [ ] Admin API permission boundaries implemented and tested
- [ ] Platform admin cannot access patient data by default
- [ ] Hospital admin limited to own tenant
- [ ] Invitations and role changes audited, with privilege escalation protection
- [ ] Licensing and usage states defined and server-enforced
- [ ] Health/status panel does not reveal sensitive environment values
- [ ] Mobile authentication and secure token storage reviewed
- [ ] Mobile deep links revalidate server authorization
- [ ] Push notifications contain no PHI
- [ ] No offline clinical data cache in initial mobile release
- [ ] Secure image/report viewing and cache cleanup tested
- [ ] Android device matrix, accessibility, and release signing tested
