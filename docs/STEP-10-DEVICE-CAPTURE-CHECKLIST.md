# Step 10 — Hardware capture validation checklist

- [ ] Exact CV-180 model, firmware, regional variant, and outputs documented onsite
- [ ] Vendor integration docs/SDK reviewed; integration rights confirmed
- [ ] Capture hardware chosen and driver/security reviewed
- [ ] Video signal path verified (no assumptions about connector/format)
- [ ] Prototype adapter boundary implemented
- [ ] Device states surfaced in UI; disconnected/no-signal distinguished
- [ ] Preview validated using non-patient test signal
- [ ] 10-minute sample recorded and played back successfully
- [ ] Frame/duration/codec/metadata checks documented
- [ ] SHA-256 computed after finalization
- [ ] Interrupted recording and recovery tested
- [ ] Disk full, capture disconnect, and app crash scenarios tested
- [ ] Encryption, authorization, private storage, and audit reviewed
- [ ] Clinical engineering and IT approval obtained
